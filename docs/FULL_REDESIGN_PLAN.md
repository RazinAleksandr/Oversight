# Full iPhone redesign: implementation plan

13 October 2026. The user authorized a substantial redesign, autonomous design
judgment and review after a new version is available. This expands the earlier
single-deployment pilot. The work remains on a separate Git branch with previous
build checkpoints preserved; no destructive rollback is required.

## Design thesis

A strategy command room: charcoal working surfaces, ivory text, amber action and
selection signals, coral danger, crisp sans-serif hierarchy. Use existing company
marks, country emblems, portraits and the map to identify real subjects. Remove
repeated paper forms, oversized chrome, ornamental containers and department
browsing from the main task path.

Landscape is the primary composition. At suitable width, a subject list and one
working detail are visible together. Compact layouts use deliberate bounded
scrolling and a sequential reading view. Essential controls keep usable hit areas;
text never shrinks merely to fit a page. Rotation preserves the task rather than
restarting a decision.

## Shared shell and decisions

The root agent owns the compact shell, agenda, contextual routing, quarter reports,
setup and title. The decision agent owns a consistent workspace for every briefing
family, action confirmation and results. The existing deployment-only workflow
becomes a general task model, retaining each authored choice, warning, cost, odds,
preview and causal follow-up.

The agenda should answer what needs a decision, what is due and what is escalating.
Related management opens directly and returns to the originating task. It does not
choose a political strategy or silently resolve mandatory decisions.

## Management interactions

- **Funding:** choose a program from the subject list; select a proposed level;
  inspect effects, current/proposed listed upkeep and the change; explicitly Apply
  or Cancel. Merely selecting a level does not mutate the game. The commit controls
  sit outside the content scroller. Actual current upkeep is distinguished from
  listed-cost projections because temporary waivers can alter charges.
- **Promises:** active/offered commitments sort ahead of completed ones. Selected
  detail brings deadline, current progress, target and conditional forecast
  together. Context links lead to the relevant funding, adoption, company, threat
  or international tool; they do not promise a particular intervention will succeed.
- **Laws:** a complete active/available catalog and one selected law with effects,
  political support, cost and an explicit review action. No nested accordion is
  required to find the action.
- **Companies:** a complete roster with fogged capability and attitude; selected
  company actions appear before long intelligence. Models retain status, evidence,
  audit/control actions and links to pending deployment or known linked threat.
- **Threats:** subject list distinguishes source, stage and response. Selected
  detail puts the current response and offered interventions before the full
  situation narrative. Warning signs and resolved history remain separate views.
- **World:** treaty progress/readiness and targeted diplomatic initiatives are
  directly available. Rival records retain all fogged intelligence and targeted
  actions. The complete international action catalog and map remain available.

## Strategic and data boundaries

Keep the deterministic engine, RNG, costs, campaign length, uncertainty, delayed
consequences and finale rules unchanged. Render fogged GameView/ActionView data only.
Company investigation does not repeat a model evaluation. A negative finding is
not proof of safety. Adoption target changes are distinct from actual uptake.
Treaty progress is distinct from signing. Forecasts disclose their assumptions.

Preserve the native shell, offline assets, save journal and signing configuration.
UI task context remains supplementary to the authoritative engine save and pending
result records. New player-visible copy must use the existing English/Russian
localization system.

## Review and verification

See [FULL_REDESIGN_QA.md](FULL_REDESIGN_QA.md) for the task matrix and deterministic
fixtures. Verify every briefing family, exact action targets and costs, funding
preview/cancel/apply, promise navigation, threats, diplomacy, quarter consequences,
save/resume, rotation and EN/RU geometry. Inspect child-content overflow and footer
occlusion, not only document width or button rectangles.

Automated completion and screenshots are engineering evidence. Human reading,
thumb reach, learning, interruptions and prolonged comfort require the physical
phone. State unverified limits accurately when delivering the new build.
