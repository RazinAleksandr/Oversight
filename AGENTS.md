# Agent instructions

Read [CLAUDE.md](CLAUDE.md) for the existing game architecture, localization, and verification rules.

For cloning, building, running, debugging, or installing the existing game on a developer's iPhone, start with [docs/IOS_COLLABORATION.md](docs/IOS_COLLABORATION.md). The iOS port already exists and was approved. Routine setup and fixes do not restart the initial port planning gate. Discover the current Mac, Apple account and connected phone; do not assume Viktor's local paths, signing team or device belong to another developer. Use command-line signing overrides for personal builds and keep the shared release identity unchanged.

When assigned the UI/UX redesign or iOS port, follow [docs/IOS_PORT_AGENT_INSTRUCTIONS.md](docs/IOS_PORT_AGENT_INSTRUCTIONS.md). Its first phase is analysis and a reviewable plan. Wait for the user's agreement on that plan before changing the game or creating the iOS port.
