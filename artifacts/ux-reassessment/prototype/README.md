# Oversight interaction study

Disposable review prototype, not the game. No save files or production UI were changed.

From repository root:

```sh
python3 -m http.server 5179 --bind 127.0.0.1
```

Open `http://127.0.0.1:5179/artifacts/ux-reassessment/prototype/`, or add `?lang=ru`.

Try: select a decision → top-bar Orbis Group → confirm investigation → return → inspect a different option → confirm. Safety funding also demonstrates a return route without losing selection. On narrow layouts, use Brief / Compare options.

Functional: selectable choices, visible comparison, contextual routes, explicit confirmations, preserved selected choice, EN/RU layout.

Staged: all data comes from the same fogged `GameAPI.view()` opening fixture; investigation and decision outcomes are independently generated by the game engine. Funding edits are local UI simulation. Quarter wrap is explicitly a flow sketch, not a real quarter report. Reload resets the study. No real save is read or written. Rotation preserves selection but not reading position. This study does not establish accessibility or physical iPhone usability.

Assets: fonts are served from the repository's existing `public/fonts`; no network fonts/dependencies. `export.ts` documents fixture generation and writes only public game views/results, not engine state. The ordinary JSON data includes no pre-reveal hidden traits; revealed company data exists only as a staged investigation result.

`check.mjs` runs the study in headless Playwright WebKit at 844×390, 667×375 and 390×844, English and Russian. It checks selection retention after contextual actions, page errors, basic horizontal overflow, and complete choice intersections/hit testing in landscape. It is not a human usability test. Screenshots are headless captures of staged moments.
